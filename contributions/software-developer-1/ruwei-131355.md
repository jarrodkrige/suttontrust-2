Recommended FirstGen Palette
Core Brand Colours
CSS:root {  --fg-ink: #1F2933;        /* Deep soft charcoal */  --fg-bg: #FFFDF9;         /* Warm off-white */  --fg-primary: #2F8F7A;    /* Calm teal-green */  --fg-primary-dark: #237363;  --fg-accent: #F0B429;     /* Warm amber */}Show more lines
Why this works

Teal-green signals growth, calm, and reassurance (excellent for education/mentoring).
Amber adds warmth and optimism without shouting.
Off‑white background avoids the harshness of pure white.


Secondary & Support Colours
CSS:root {  --fg-muted: #6B7280;      /* Muted grey for body copy */  --fg-soft-green: #E6F4F1; /* Section backgrounds */  --fg-soft-amber: #FFF3DA;/* Highlight panels */  --fg-divider: #E5E7EB;   /* Subtle borders/dividers */}Show more lines
Why this works

Soft tints create breathing space between sections.
Muted grey improves readability and reduces visual stress.
Gentle contrasts help users scan long pages comfortably.

Accessibility Check (Quick)

All text on --fg-bg and --fg-soft-* passes WCAG AA for normal text.
CTA buttons with white text on --fg-primary meet contrast requirements.
Colours remain distinguishable for common forms of colour‑vision deficiency.
